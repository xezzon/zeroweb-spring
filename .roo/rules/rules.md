# ZeroWeb 代码贡献规范 (Roo Agent)

作为 Roo Agent 为 ZeroWeb 项目贡献代码时，请遵循以下关键规范：

1.  **核心技术栈**: 项目基于 Java 和 Spring Boot。
2.  **参考文档**: 详细的开发指南请参考项目的 `CONTRIBUTING.md` 文件。

## Roo Code 工作流程

请按照以下步骤进行代码贡献：

1.  **设计文档**: 在编写代码前，先完成设计文档的编写，并更新到当前功能模块目录的 `README.md` 文件中（例如 `zeroweb-service/zeroweb-service-admin/src/main/java/io/github/xezzon/zeroweb/auth/README.md`）。
2.  **代码实现**: 根据设计文档实现代码。
3.  **单元测试**: 为实现的代码编写单元测试。
