# 附件管理服务

## 配置清单

| 变量                         | 描述                                                                            | 默认值 |
|----------------------------|-------------------------------------------------------------------------------|-----|
| ZEROWEB_FILE_PROVIDER      | 文件存储后端。<br/>可选值：`FS`, `S3`                                                    | FS  |
| S3_ENDPOINT                | S3访问地址。存储后端为`S3`时必填。                                                          |     |
| S3_REGION                  | S3存储区域。                                                                       |     |
| S3_ACCESS_KEY              | S3访问密钥ID。存储后端为`S3`时必填。                                                        |     |
| S3_SECRET_KEY              | S3访问密钥。存储后端为`S3`时必填。                                                          |     |
| S3_BUCKET                  | S3存储桶。存储后端为`S3`时必填。                                                           |     |
| S3_PART_SIZE               | 单个分片大小限制，不能小于5。单位：MB。                                                         | 5   |
| ZEROWEB_FS_BASEPATH        | 用户上传文件的存储目录。存储后端为`FS`时必填。<br/>注意：使用Docker运行时，该目录是容器内的路径，务必将其映射到宿主机，否则会导致数据丢失。 |     |

其他配置请查看[公共配置清单](../../zeroweb-spring-boot-starter/README.md)。
