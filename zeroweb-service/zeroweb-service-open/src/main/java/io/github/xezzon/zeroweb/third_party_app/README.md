# 第三方应用管理

## 模块简介

第三方应用管理模块用于对外部系统或开发者注册的第三方应用进行统一管理，包括应用的注册、密钥管理、权限校验、订阅关系等。该模块为平台开放接口提供安全认证和授权能力。

## 主要功能

- 第三方应用的注册与信息维护
- 应用密钥（AccessKey/SecretKey）生成与轮换
- 应用权限校验，仅应用所有者可管理
- 查询当前用户的第三方应用列表
- 查询所有第三方应用（管理员权限）
- 查询第三方应用的接口订阅情况
- 支持OData风格的分页与排序

## 主要接口说明

### 1. 添加第三方应用

- **接口**：`POST /third-party-app`
- **描述**：注册一个新的第三方应用，自动生成密钥。
- **返回**：`AccessSecret`（包含accessKey和secretKey）

### 2. 获取当前用户的第三方应用列表

- **接口**：`GET /third-party-app/mine`
- **描述**：分页查询当前登录用户的所有第三方应用。

### 3. 查询所有第三方应用

- **接口**：`GET /third-party-app`
- **描述**：分页查询所有第三方应用（需管理员权限）。

### 4. 查询应用的订阅情况

- **接口**：`GET /third-party-app/{appId}/subscription`
- **描述**：查询指定应用已订阅的接口及其状态。

### 5. 轮换应用密钥

- **接口**：`PATCH /third-party-app/{appId}/roll`
- **描述**：重新生成指定应用的密钥，仅应用所有者可操作。

## 权限说明

- 只有应用所有者可以管理和轮换自己的应用密钥。
- 管理员可查询所有应用。

## 数据结构

- `ThirdPartyApp`：第三方应用实体，包含id、name、ownerId、createTime等字段。
- `AccessSecret`：应用访问凭据与密钥，包含accessKey和secretKey。

## 典型流程

1. 用户注册第三方应用，获得accessKey/secretKey。
2. 用户可随时轮换密钥，提升安全性。
3. 用户可查询自己注册的所有应用及其订阅情况。
4. 平台通过accessKey/secretKey对第三方请求进行认证和授权。
