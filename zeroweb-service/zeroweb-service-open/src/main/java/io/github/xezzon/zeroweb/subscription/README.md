# 接口订阅

## 目标
为第三方应用提供对外接口的订阅、审核和管理能力，实现接口调用的权限控制。

## 主要功能
- 订阅接口：第三方应用可发起对已发布接口的订阅申请。
- 审核订阅：管理员可对订阅申请进行审核，审核通过后订阅生效。
- 查询订阅：支持按应用分页查询已订阅接口及其状态。
- 权限校验：只有应用所有者可管理本应用的订阅。
- 调用校验：确保只有已订阅并审核通过的接口可以被调用。

## 约束
- 只能订阅已发布的接口。
- 同一应用对同一接口只能有一条有效订阅记录。
- 订阅状态包括：审核中、已订阅、未订阅等。
- 未审核通过的订阅无法调用接口。
- 内部路径信息不会暴露给订阅者。
