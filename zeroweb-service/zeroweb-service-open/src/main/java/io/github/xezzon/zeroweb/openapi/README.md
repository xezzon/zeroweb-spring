# 对外接口管理

## 模块简介

`openapi` 模块用于管理对外接口的生命周期，包括接口的注册、发布、修改和查询。通过该模块，第三方应用可以订阅和调用已发布的接口，实现统一的接口管理。

## 主要功能

1. **新增对外接口**  
   支持录入接口编码、后端地址、HTTP 方法等信息，接口状态默认为草稿。

2. **修改对外接口**  
   支持未发布接口的信息变更，已发布接口的编码不可修改。

3. **发布接口**  
   将接口状态从草稿变更为已发布，发布后接口可被第三方应用订阅和调用。

4. **分页查询接口**  
   支持 OData 风格的分页、排序和过滤，便于快速检索符合条件的接口。

5. **查询接口详情**  
   根据接口编码查询接口的详细信息。

## 接口说明

### 新增接口

- **路径**: `POST /openapi`
- **描述**: 新增一个对外接口。
- **响应**: 返回新增接口的唯一标识符。

### 修改接口

- **路径**: `PUT /openapi`
- **描述**: 修改未发布的对外接口信息。

### 发布接口

- **路径**: `PUT /openapi/publish/{id}`
- **描述**: 发布指定的对外接口。

### 查询接口列表

- **路径**: `GET /openapi`
- **描述**: 分页查询对外接口列表。
- **查询参数**: 支持 OData 风格的分页、排序和过滤。

### 查询接口详情

- **路径**: `GET /openapi/{code}`
- **描述**: 根据接口编码查询接口详情。

## 注意事项

- 接口编码必须唯一，且发布后不可修改。
- 只有已发布的接口才能被订阅和调用。
- 发布接口后，编码（即对外路径）不可变更。
- 所有接口操作需遵循模块的权限控制策略。
