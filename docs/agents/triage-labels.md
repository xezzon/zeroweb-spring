# 分诊标签（Triage Labels）

工程类技能统一以五种标准化的"分诊角色"沟通。本文件将这些角色映射到本仓库 issue tracker 实际使用的标签字符串。

| mattpocock/skills 中的角色 | 本仓库实际标签 | 含义 |
| -------------------------- | -------------- | ---- |
| `needs-triage`             | `needs-triage` | 维护者尚需评估此 issue |
| `needs-info`               | `needs-info`   | 等待报告人补充更多信息 |
| `ready-for-agent`          | `ready-for-agent` | 规格已完备，可交由离线 agent 实现 |
| `ready-for-human`          | `ready-for-human` | 需要人工实现 |
| `wontfix`                  | `wontfix`      | 不予处理 |

当某个技能提及某一角色（如"打上 AFK-ready 分诊标签"）时，请使用本表右栏对应的标签字符串。

如本仓库实际使用的标签不同，请修改右栏字符串。
